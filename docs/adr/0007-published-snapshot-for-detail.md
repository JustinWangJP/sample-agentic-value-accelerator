# 連絡先・利用条件・接続先の参照は、補助テーブルの公開版スナップショットに置く

カタログ項目の詳細には、所有チームのほかに連絡先・利用条件・接続先の参照・関連参照を表示する。これらは検索や絞り込みに使わない。custom metadata には検索や絞り込みに使う属性だけを定義する（設計書「共通項目と custom metadata」）。そこで、これらの値は補助テーブルに置き、公開承認した版ごとの公開版スナップショット（`sk` = `PUBLISHED#{recordVersion}`）から読む。所有チームの正本は、引き続き管理情報（`sk` = `MANAGEMENT`）に置く。

## 検討した選択肢

- custom metadata に `contact`・`termsOfUse`・`connectionReference` を追加する案は採用しない。検索に使わない属性で schema を広げることになり、版との対応も取れないためである。

## 影響

- 公開承認（#10）で、申請のスナップショットの値を公開版スナップショットへ写す。属性の型は [README の「詳細」](../../applications/registry_portal/README.md#詳細)に記載する。
- 公開版スナップショットがない版（未管理レコードなど）では、これらの値を「未取得」と表示する。スナップショットはあるが値がない項目は「未登録」と表示する。
- 補助テーブルを読めない場合や、型が取り決めと異なる場合は、custom metadata に頼らず 502 とする。
