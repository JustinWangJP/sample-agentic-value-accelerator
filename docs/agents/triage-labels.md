# Triage ラベル

各スキルは 5 つの標準 triage ロールで会話する。このファイルは、それらのロールとこのリポジトリの Issue tracker で実際に使うラベル文字列を対応付ける。

| mattpocock/skills のラベル | このリポジトリのラベル | 意味                                         |
| -------------------------- | ---------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`         | メンテナーによる評価が必要                   |
| `needs-info`               | `needs-info`           | 報告者からの追加情報待ち                     |
| `ready-for-agent`          | `ready-for-agent`      | 仕様確定済み。AFK エージェントが着手可能     |
| `ready-for-human`          | `ready-for-human`      | 人による実装が必要                           |
| `wontfix`                  | `wontfix`              | 対応しない                                   |

スキルがロールに言及した場合（例:「AFK 着手可能の triage ラベルを付ける」）は、この表の対応するラベル文字列を使う。

実際に使うラベル名が変わった場合は「このリポジトリのラベル」列を編集する。
