# Registry ポータルのレビュー基準

レビューでは、次の判断を差分と関連するテストに照らして確認する。

- 外部 API の入力制約と挙動は公式ドキュメントで確認し、根拠を README の該当箇所へリンクする。SDK モデルと説明が異なる場合は、その差と実環境で確認できた範囲を記録する。
- 種別やデータ分類の値は、バックエンドとフロントエンドのそれぞれで一か所に定義する。言語間の値と意味を揃え、変更時は両側の利用箇所を確認する。
- 0件、未取得、準備中、失敗を利用者が区別できるか確認する。通信や保存内容の異常を空の結果に変換しない。HTTP 応答と画面表示の両方をテストで確認する。

設計判断は [ADR-0006](../../docs/adr/0006-a2a-search-metadata-as-copy.md) と [ADR-0007](../../docs/adr/0007-published-snapshot-for-detail.md)、用語は [GLOSSARY.md](../../GLOSSARY.md) を参照する。

import の禁止パターンは `scripts/check_imports.py` が検査する。レビュー規約へ同じ禁止事項を追加する代わりに、この検査と違反例のテストを更新する。
