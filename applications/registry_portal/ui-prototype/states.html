状態・エラー・デザインシステム一覧

本番 React 実装時に共通コンポーネント化する状態表現・エラーハンドリング・バッジの仕様確認用ページです。

1. 起動・失敗（401・403・5xx の厳密な区別）

401 だけが再ログイン、5xx だけが再試行を表示します。403 はログインし直しても再試行しても解決しないため、どちらのボタンも表示しません。各業務画面では、プロトタイプ確認用バーの「表示状態」で同じパネルを一覧領域に重ねて確認できます。

ログインしています…

SSO 認証および主体情報の取得中

2. 「0 件」「未取得」「準備中」「失敗」の 4 状態

「失敗」は 1. の 401・403・5xx を参照してください。0 件・読み込み中・準備中のパネルも業務画面の一覧領域と共通です。

未取得（スナップショットなし）

連絡先・利用条件・接続先の参照は「未取得」です

未管理レコードまたは公開版スナップショット未保存のため取得できません（「未登録」とは区別して表示します）。

3. 業務固有の警告・制約バナー

403 FORBIDDEN

申請者と最終編集者は決裁できません。別の Curator が審査してください。

自己承認かどうかは決裁の送信時にサーバーが判定します。公開承認・却下のボタンは事前に無効化せず、返ったメッセージをそのまま表示します。ログインし直しても解決しないため、再ログインボタンは表示しません。

この申請は審査中の編集で無効になっています 決裁できません。一覧で最新の状態を確認してください。
申請スナップショットが申請時の内容と一致しません 保存された申請スナップショットが申請時の内容と一致しません。決裁できません。Publisher に再申請を依頼し、管理者に連絡してください。
所属チームが割り当てられていません（Publisher） 業務ロールに Publisher を持っていますが、Cognito の所属チーム（team-*）が未設定のため、下書きの作成・編集・申請・廃止依頼は行えません。管理者にチーム割当てを依頼してください。

4. 状態バッジ・ラベル一覧

公開中（APPROVED） 審査待ち（PENDING_APPROVAL） 下書き（DRAFT） 公開停止中（AWS 状態: REJECTED / 検索値: SUSPENDED） 廃止済み（DEPRECATED） 結果確認中（VERIFYING） A2A public private

※ SUSPENDED は管理レコード検索専用の絞り込み値であり、AWS Agent Registry 上の状態は REJECTED です（GLOSSARY.md 参照）。
