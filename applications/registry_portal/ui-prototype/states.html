状態・エラー・デザインシステム一覧

本番 React 実装時に共通コンポーネント化する状態表現・エラーハンドリング・バッジの仕様確認用ページです。

1. 起動・認証エラー（401 と 403/5xx の厳密な区別）

ログインしています…

SSO 認証および主体情報の取得中

401 UNAUTHENTICATED

認証が必要です。ログインし直してください。

※ 401 またはログイン失敗のときだけ再ログインボタンを表示します。

403 FORBIDDEN / 502

この操作を行う権限がないか、現在サービスを利用できません。

requestId: req-01jd9x...

2. 「0 件」「未取得」「準備中」「失敗」の 4 状態

0 件（正常応答）

該当するカタログ項目はありません

検索条件を変えるか、別の種別タブを確認してください。

未取得（スナップショットなし）

連絡先・利用条件・接続先の参照は「未取得」です

未管理レコードまたは公開版スナップショット未保存のため取得できません（「未登録」とは区別して表示します）。

準備中（503 A2A_SEARCH_NOT_READY）

A2A での絞り込み検索は現在準備中です

A2A の Agent を探す場合は、一覧画面の「A2A の Agent のみ表示」をご利用ください。

A2A の Agent 一覧を開く →
失敗（502 DISCOVERY_UNAVAILABLE）

カタログの取得に失敗しました

一時的な通信異常またはサービス障害のため結果を表示できません（0 件ではありません）。

3. 業務固有の警告・制約バナー

自己承認禁止：この申請は決裁できません 申請者または最終編集者があなた自身と一致しているため、公開承認・却下のボタンを無効化しています。別の Curator に決裁を依頼してください。
申請スナップショットとの不整合（無効化 / 改ざん警告） 保存済みの申請スナップショットと現在の Registry レコード内容が一致しません。決裁は実行できません。Publisher による再申請または Admin の確認が必要です。
所属チームが割り当てられていません（Publisher） 業務ロールに Publisher を持っていますが、Cognito の所属チーム（team-*）が未設定のため、下書きの作成・編集・申請・廃止依頼は行えません。管理者にチーム割当てを依頼してください。
通知の取得に失敗しました。通信状況を確認のうえ再試行してください。

4. 状態バッジ・ラベル一覧

公開中（APPROVED） 審査待ち（PENDING_APPROVAL） 下書き（DRAFT） 公開停止中（AWS 状態: REJECTED / 検索値: SUSPENDED） 廃止済み（DEPRECATED） 結果確認中（VERIFYING） A2A public private

※ SUSPENDED は管理レコード検索専用の絞り込み値であり、AWS Agent Registry 上の状態は REJECTED です（GLOSSARY.md 参照）。
